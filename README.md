# Login-Register-API---Java-spring-boot
This is java Spring Boot project that expose me to understanding Controllers, Services, DTOs, Validation, Password hashing, Database connection, Authentication basics

## Features
- User registration
- User login
- DTOs
- Validation
- Password hashing with BCrypt
- H2 database
- Spring Security configuration

## Endpoints
POST /api/auth/register
POST /api/auth/login
